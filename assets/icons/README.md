# Pocket Pitch icon

Created with the built-in image generation tool.

- `pocket-pitch.png`: full-resolution project and classic Android launcher icon.
- `pocket-pitch-adaptive-foreground.png`: transparent 432 × 432 Android foreground. The generated emblem is fitted inside a 252-pixel circle, leaving a margin within Android's 264-pixel safe zone.

The original Godot `icon.svg` is retained but is no longer the project icon.

## Main icon prompt

Use case: logo-brand. Asset type: square Android launcher icon and Godot project icon for Pocket Pitch, a colorful top-down flick soccer game with circular team discs. Create one production-ready 1024x1024 icon, no mockup. Subject: a large warm ivory soccer ball with dark navy pentagonal patches, in front of two smaller round playing discs, one vivid coral-red and one bright turquoise, evoking a flick soccer tabletop game. Style: bold clean retro arcade illustration, crisp geometric silhouettes, restrained dimensional shading and short graphic shadows, simple enough to read at 48 pixels; match a game with a deep navy interface, striped emerald green soccer pitch and warm cream markings. Composition: centered compact emblem occupying the central 65 percent of the square, all important shapes safely inside a centered circular crop, ball most prominent, discs partially visible behind it, subtle cream center-circle field marking behind the emblem. Background: full-bleed rich emerald green with very subtle broad alternating pitch stripes, opaque all the way to the square edges. No text, letters, numbers, logos, watermark, border, outer rounded-square outline, or photographic detail. Deliver only the finished square icon artwork.

## Adaptive foreground prompt

Use case: background-extraction. Edit target: the supplied Pocket Pitch icon. Create its Android adaptive-icon foreground as a square transparent PNG. Keep the same ivory-and-navy soccer ball and the red and turquoise tabletop playing discs with their existing illustration style, relative arrangement, highlights and colors. Remove ALL green pitch, field stripes, cream field lines, center circle, and every background pixel, leaving true alpha transparency around the three-object emblem. Keep short shadows only directly attached to the objects. Scale and center the complete three-object emblem down so ALL nontransparent pixels fit entirely inside the central circle of diameter 58 percent of the square image; leave broad fully transparent padding on every side. This safe-zone padding is mandatory for Android launcher masks. No words, text, border, glow, background or checkerboard pattern. The output must have genuine transparent pixels.
